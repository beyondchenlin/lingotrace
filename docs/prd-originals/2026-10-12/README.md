# LingoTrace 独立 PRD 原始文档归档

本目录保存 2026 年 10 月 12 日找回的 48 份独立 PRD 文档，共 31 份 Word（DOCX）和 17 份 PDF，总计 18,330,358 字节。文件名和每个文件的原始字节均保留；未改写、重新生成、转换格式或以较新内容覆盖较旧文件。

## 如何使用

- [originals](originals/)：原始 Word / PDF 文档。
- [MANIFEST.json](MANIFEST.json)：逐份文件的原始名称、相对路径、字节数、SHA-256 和 Git blob SHA-1。
- 本次范围包含 v1.2、v1.3、v1.4 系列，以及文件名标注 2026-10-12 的 v1.4.8 执行校准版总纲和详细 PRD。以清单中的实际文件为准，不据此推断所有曾经存在的版本都已找回。

## 历史状态与归档边界

这些是独立 PRD 原件的历史归档。文件中的需求、批准、暂停、待讨论、已发布、未完成和未验证等状态，均属于各文档记载的时点。保留旧版本不表示当前仍沿用其全部状态，也不表示所有文档都已被接受或都是最新版本。版本号、文件时间和本次归档时间，不能替代后续明确的需求决策与验收证据。

本次仅补齐这些独立文档的归档，不等于功能已经实现，不等于测试、真机验收、合并或部署已经完成，也不等于完整源码、全部素材或全部 Git 历史已经恢复。仓库中的其他需求增补、证据文件和源码检查点具有各自的范围；本目录不覆盖它们。

原文中保留了项目相关的要求引述、消息来源标识、实现和部署记录，以及参考链接。这些原有内容未被删改或重新解释。对当前状态的说明应另行记录，不回写历史原件。

## 原字节校验

全部 48 个本地文件的字节数与来源文件元数据一致。31 个 DOCX 均通过 ZIP CRC 完整性检查；17 个 PDF 均可打开并提取文字。清单的 SHA-256 校验原始文件字节；Git blob SHA-1 对应 Git 对象头与原始文件内容，便于与仓库中的对象核对。此类校验说明文件保存一致性，不是功能或需求验收。

文件名含 `(1)` 的 v1.3 PDF 和 v1.4 PDF，分别与其不含 `(1)` 的同版本 PDF 字节完全一致。为保留原始文件身份，四个文件名均保留，未去重改名。
