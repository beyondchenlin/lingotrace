## 已证实的源码缺陷
原生 textarea 的 Canvas 投影用离屏 DOM Text 和 Range 测量。旧缓存仅比较输入值及样式，未核对缓存 Text 的当前内容与 DOM 归属。外部页面处理若缩短或拆开 Text，而 textarea 不变，后续 Range 仍使用完整输入的偏移，真实浏览器会抛 IndexSizeError，阻断这一帧。

隔离真实浏览器用合成 hello preserved 验证：旧实现缩短/拆分 Text 后，setStart 的偏移5超过节点长度1并抛 IndexSizeError；修正后五个原生 DOM 情况均通过，完整文字、镜像连接状态、输入值和选择保持。此红绿证据证明缺陷及修正条件，尚不能确认用户手机使用了同一外部处理。

## 本次范围
1. 每次使用测量缓存前，核对并恢复完整 UTF-16 文本、双子节点结构、直属 body 的镜像和空基线节点；重新测量损坏的缓存。
2. 保留空文本/末尾换行的测量哨兵，不靠裁短输入或限制 Range 偏移来掩盖损坏。
3. 仅对学习文本区域、textarea 和测量镜像设置 translate=no；界面菜单及全站语言功能不被禁用。
4. 实际错误对话框增加固定白名单阶段/异常名，成功恢复后清除。不得显示草稿、参考文本、路径、URL、原始错误信息或堆栈，也不加入普通 HUD。
