## Detailed-document delta

SceneMedia.lesson selects the native owner for the existing Canvas video. Continuous mode never navigates Training cues. Optional repeats are finite by default, unlimited only when explicitly selected, with cancelable inter-repeat pause. Whole-practice pause cancels the pending repeat delay and preserves the position; continuing practice never starts media. A subsequent explicit Continue Listening resumes an active repeat or fixed type cue from its beginning when already at that cue’s completed boundary. It preserves the selected total number of passes, consuming a remaining pass when its restart is admitted or an explicit seek re-enters it from the completed boundary, and cancels any older delay. In listen mode, Continuous Listening instead exits the repeat scope and carries on from the current position. Type mode retains its approved fixed-cue boundary. Replayed listening wall time is separately observed, while media coverage stays a union and is not added twice; no repeat action creates Training input or attempts.

The reference card is a Canvas visual separate from the textarea. Sentence-level grapheme interpolation uses currentTime, declared as estimated rhythm rather than word/acoustic alignment. ### Time and persistence

Adjacent same-boundary monotonic samples produce explicit half-open spans. Maximum accepted gap is 1500 ms and media consistency tolerance 0.12 seconds, versioned as listening-observed-v1. These are conservative implementation parameters requiring browser/device calibration, not a physical accuracy guarantee. Rate/seek/waiting/mute/visibility/permission and owner changes split spans. Frozen or unobserved gaps are unknown, not filled from played or media/wall differences.

L is verified native course playback wall time; T is observable explicitly selected type-mode practice after first play or input, including reading/thinking while only video is paused. Hidden excludes T. Native hidden L counts only continuously observed subset. Effective time is union(L,T); overlap and background are subsets, never added again. Same-media coverage is a separate media-axis union. Each saved observation has its own clock; no deduplicated cross-tab total is claimed. Old activeMs remains separate.

Metrics enter existing meta only after page-local permission admission; OFF synchronously revokes and cancels pending writes. ON creates a new observer/cursor after admission, without prior temporary tails. Stored records include no answer/reference text. Revision/prefix/identity checks, zero-write readers, missing-head and sealed-head refusal apply. Every displayed saved status follows transaction completion. Temporary manual export is marked accordingly.

### Lifecycle and recovery

Explicit finish waits for an in-flight metric write then seals the remaining tail. A failed explicit save retains the paused observer and propagates failure, allowing retry or manual export. Course/reference/new-round/retest transitions flush B scope before reset; no implicit round ending occurs merely on entering listen. Pagehide attempts captured permitted flush before revocation; unload can still prevent completion, so only committed history is called saved and reload coverage is unknown. OFF has precedence and never flushes first.
