## 1 用户目标和合同优先关系

2026-10-12 14:02 UTC，用户说明：“用户的手打字能真的跟得上这个视频里的声音的这个速度”，希望“正好也打完了，人家也说完了”，以此“锻炼用户……肌肉记忆”。因此主训练的方向是声音按已选择的节奏播放，用户真实手打跟上。准确文字、声音与动作节奏的协调是训练目的，尚不能称已有经验证的肌肉记忆提升或英语能力评估。

此前“根据打字速度自动播放视频”的要求形成了自适应 Follow 及首次真实输入自动开始。本次校正主次关系：固定所选速率成为主训练，旧自适应作为明确选择的辅助保留。视频被打字放慢后，两端同时结束不证明用户能在同一句原速下跟上。真实输入自动开始这一便捷入口仍保留，但不再默认意味着输入决定媒体速率。

本稿只覆盖与本次方向冲突的默认模式、播放调速和结果解释；不取消 F01–F14 其余目标，也不解除既有未批准范围。具体五档速率及本页临时指标属于本批选定的实现范围，不伪称用户原话已经指定这些参数。

## 3 模式与进入规则

### 3.1 固定语速主模式

FIX 01：本批新鲜合格 NPS 普通跟打默认固定 1×。可显式选定 0.5×、0.8×、1×、1.25×、1.5×；选择本身不播放、不改答案。UI 分开显示所选值和原生实际值；未读回成功不显示已经按该速率运行。默认和选择只在本页控制状态使用，不新增持久偏好或迁移。

FIX 02：同次运行的播放速率独立于输入速度、输入正确性、正确前缀、目标长度、CPM 和动效。正常停打超过 1500ms 不减速，不进入 idle-coasting。用户快打、慢打或错误追加均不使固定速率变化。用户主动改速必须结束该次连续测量，再按新选择显式开始，不能静默续接原结果。

FIX 03：本批可复用 v93 一次机会的来源和撤销规则：明确没有旧记录的新鲜初始化、用户成功新开练习、未恢复的新练习首次明确进入尚未获得机会的新句。第一次可信末尾追加才消费机会；机会准备不播放。首次资格受阻、非合格编辑、初次 IME 取消等不循环重试。手动停止、返回前台、focus、显示参考、恢复旧稿或返回已使用句均不重备。

FIX 04：显式开始和自动开始共享媒体资格与 owner 防护；原生 play 与既有音频路由恢复在同一有效手势链请求，均完成后才报启动成功。拒绝时暂停并给显式重试入口；后续字符不能反复调用 play。输入立即通过原编辑器，不等待播放或异步存储。

FIX 05：一份已验证原生视频同时提供原声、画面、currentTime 和 playbackRate。仅允许原有进入动作的一次句首定位及用户显式重播／定位；没有按字符或按正确前缀 seek。音频、字幕、媒体字节和时伸处理不改变，不添加第二条声音。

### 3.2 自适应辅助模式

ASSIST 01：保留旧自适应 Follow，由用户显式选择后才使用；不作为固定播放失败、打慢或未完成时的自动回退。入口、状态、帮助统一标识“自适应辅助／Adaptive assist”。它可用于放慢熟悉内容，但不产生本稿固定条件时差或“原速跟上”的判断。

ASSIST 02：旧合同继续有效：0.8×起步、0.5–1.5×、200ms 控制间隔、3 秒窗、至少 1000ms 覆盖及两次相隔至少 250ms 的合格提交、0.25/s 斜率、0.02 死区、1500ms 后 idle-coasting，最终句尾停止。所有参数仅是既有实现值，不称经过真人研究验证的最佳参数。

ASSIST 03：自适应 IME 预编辑等待和同组合最终提交恢复保持现状。该等待是辅助行为，不能借此形成固定语速证据。旧临时估速与现有 5 秒 CPM 始终分开。

### 3.3 素材和参考条件

本批只支持已验证的原 NPS 身份、完整登记句映射、合法有限范围和当前媒体 lease；参考须真实显示并已记录相应暴露，练习可编辑、前台且无冲突 owner。保持现有 NPS 限制，不删除校验以扩展咖啡馆或自由视频。

固定与自适应都必须如实标参考可见。固定 1×仍可有参考、重听、提示或其他帮助；“原速”和“无辅助”不是同一条件。隐藏时先撤销控制和答案推导显示；本批不开放隐藏听写固定主路径。未来隐藏听写需单独满足既有无泄露、内嵌字幕和辅助证据合同。

## 4 停止 中断和输入完整性

| 事件 | 固定主模式要求 | 本次时差 |
|---|---|---|
| 正常无输入或可信错误追加 | 原速率继续到当前句尾 | 可继续观察；准确度等显式 Check |
| 实际达到登记句尾 | 正常停止，不下一句；允许用户补完输入 | 有资格保留句尾观察，等待合格提交 |
| IME composition-start | 安全中断本次，不等候后自动恢复 | 未知；最终提交不得复活资格 |
| 粘贴、删除、替换、中间编辑、撤销或来源不明 | 保留原生编辑，不制造速度；沿安全策略结束或撤销测量资格 | 不能冒充完整可信追加链，未知 |
| 手动暂停、停止、seek、重播或变速 | 用户动作优先，撤销当前范围及自动机会 | 当前结果未知；新运行须新身份 |
| 后台、失焦、pagehide、切句／源、Hidden、模态、检查中断、媒体错误 | 安全退出，不以恢复显示或迟到异步回调续播 | 未知，不补算中断段 |
| 开始录制 | 在捕获前停止并完成原 owner 交接 | 当前测量失效；不新增录制指标 |
| 页面恢复或旧练习恢复 | 不恢复 active、计时样本、play 请求或自动机会 | 历史缺测保持未知 |

每次速率、边界、原生事件及异步结果继续绑定 source／cue／owner／epoch／command。旧范围不能暂停或改速较新 owner；恢复旧手动速率须仍持有对应令牌及预期原生值。固定或自适应均不得为保住测量而抵抗用户手动控制。

固定 IME 中断是本批保守实现选择，因此连续 IME 输入的完整固定节奏训练仍存在体验缺口；不能称所有输入法已获得同等有效计时支持。其真实最终输入及旧 CPM 仍按原合同处理，不能为了保住连续时差假造逐键提交。

### 5.1 独立维度

| 维度 | 可报告内容 | 禁止推定 |
|---|---|---|
| 文字准确性 | 现有显式 Check 对固定版本参考产生的 attempt 结果和 errors | 英语等级、听懂、发音、首位置准确率或其他未实现公式 |
| 句尾完成时差 | 本页合格运行的末次可信追加相对已观察登记句尾的有符号差 | 逐词落后、真实声学句尾、逐字同步、永久进步分 |
| 速率 | 用户所选固定档和原生读回值，或明确自适应 | 0.8×等同原速；自适应平均为 1×等同连续原速 |
| 参考与帮助 | 本句真实显示参考、重听、提示等可证明条件；缺测为未知 | 缺少帮助字段等同从未看过答案 |
| 输入率 | 现有版本化 5 秒 CPM；IME 与直接输入来源边界 | CPM 等于已跟上声音；动效 pace 等于 CPM |
| 训练效果 | 本次具体练习事实；未来需独立设计的同条件复测 | 单次结果证明肌肉记忆形成或总体英语水平提升 |

### 5.2 本页临时句尾完成时差

MEASURE 01：指标只属当前页、当前新运行、当前源／句／参考版本。必须能够归属完整本次输入和同一个提交稿。运行前已有草稿、重播带已有完整答案、恢复旧稿或来源链不完整，不足以证明完整本句跟打；时差保持未知。自动开始的首个触发字符允许早于原生开始，应明确属于启动方式，不能偷偷把原生播放延迟归因于用户听力。

MEASURE 02：使用同一单调时钟记录“观察到已登记句尾”的时刻和末次可信 committed tail append 的时刻，定义 deltaMs = lastTrustedAppendMs − observedCueEndMs。负数表示末次追加早于观察句尾，正数表示晚于观察句尾。不要取绝对值，不把负数清零，也不将任何接近零的值自动分类为“完美同步”。

MEASURE 03：句尾必须由本次真实运行的媒体进度和当前 owner 边界检查实际观察；`(cue.end − cue.start) / selectedRate` 只能给名义时长，不能代替真实句尾。不能用 wallTime、提交点击时间、activeMs、CPM 窗口、动效或最终文本长度反推该值。媒体暂停、缓冲、源变化、观测缺口、原生速率未生效及不可归属事件使连续测量不完整；无充分证据即未知。

MEASURE 04：仅显式 Check 已产生现有合法 attempt，且 errors=0、提交稿的 inputRevision 与末次可信追加修订一致、所需输入链仍完整，才显示数值。不是仅凭文本长度或预先比较隐藏答案就宣布完成。IME 最终提交恰好一次，程序 input、粘贴和同稿重复 Check 不产生新完成时差；旧 attempt 不能与新句尾拼接。

MEASURE 05：提前打完可在句尾到达后再 Check，得到负值；如提前 Check 已触发安全停止且尚未观察句尾，则结果未知。句尾后补齐到全匹配可得到正值。未全匹配、无有效 attempt、错字待改、空稿、句尾未观察或任一中断均未知，不以 0 表示缺测。错误稿仍保留现有准确度反馈，不能因新时差未知而丢弃旧结果。

MEASURE 06：读数只描述浏览器观察的登记字幕边界与最终追加，不是实际扬声器声学时刻。显示单位与小数位必须符合已验证的观察精度；未经采样和边界误差核验，不能展示毫秒级精度或写“刚好同时”。NPS 句界未独立声学校准，无逐词时间戳；字符均匀插值只能是估算展示，不能升级为逐词 lag。没有已批准且验证过的误差阈值，不新增通过／失败门槛或排名。

MEASURE 07：已知静音、音量零、课程声音路由挂起或播放失败时，不能把文字与视频的时间关系描述为有效听打匹配；本批时差保守显示未知及原因，不自行取消静音。即使页面所知路由可听，也不证明系统音量、耳机状态、注意力或实际听懂。

MEASURE 08：时差为本页临时观察值，不进入 Training/Practice schema、IndexedDB、旧事件流、日历、导出、成果、XP、分享卡或录制画布，不新增持久化许可或键盘事件日志。只保留实现所需的有界时间、修订和身份状态，不额外保存输入文字；退出范围清理，刷新后未知。

### 5.3 建议结果文案

合格结果例：“固定 1× · 参考已显示 · 本次检查全匹配 · 句尾完成时差：晚 0.8 秒”。附短说明：“按本次末次追加与观察到的字幕句尾估算，不是逐词同步或能力评分。”示例数值仅演示格式，不是验收阈值或真实用户成绩。

缺测例：“本次时差未知：输入法组合已中断连续观察。”或“本次时差未知：检查前尚未观察到句尾。”自适应例：“自适应辅助 · 实际速度 0.72× · 参考已显示”；不附固定语速达标标签。
