# F09 private saved-result card — bounded v46

Base: accepted responsive entry v45 `4ddc504aaa5f62dc52cdf7aa8b5b54abae55fdcb`. This adds a private, user-requested PNG path inside an existing complete Training v1 history detail. It does not implement video redaction, external publishing, future Practice adoption, or complete F09.

The selected immutable history snapshot is the source. Its session/sequence/material/metric lineage remains internal to the existing reader and guarded download boundary. The card projection reuses the existing checked history-HUD projection; original earnedWords and saved completion numerator/denominator are not rescored. Embedded material/version proof is required. Partial segments never enter this feature, and missing evidence does not become a zero-valued achievement. A legitimate saved zero remains zero.

The preview lets the user select confirmed words and/or completion. One field must remain selected. Only those primitive quantities and fixed labels reach the fresh 1200×800 Canvas. The original record's title, answer, draft, IDs, precise dates/times, camera and audio are not supplied to the card renderer. There are no private image/video sources or arbitrary strings in the export model. Filename is the fixed `lingotrace-practice-card.png`; ordinary browser PNG encoding does not include our record JSON or an editable project. The visible accessible preview description follows the selected fields.

Preview and export use the same drawn canvas. PNG creation is asynchronous; after it completes, the existing repository `deliverHistorySession` rechecks the original durable snapshot inside its readonly transaction before synchronous download handoff. Cancel, unmount, record navigation or field changes invalidate pending work; duplicate clicks do not start duplicate encodes. Failed/stale generation does not claim a download or alter the saved session. The same card may be downloaded again only through another explicit click.

Field choices and the canvas live in memory. This feature does not save cards, change history recording settings, upload, open a share destination or access cameras/microphones. An already downloaded file outside application control cannot be recalled. Existing full JSON/CSV exports keep their original records and semantics. Cancelling returns keyboard focus to the preview button. Drawing/encoding failures are explicit and retryable.

Verification is split: deterministic projection/privacy and real Canvas program checks; isolated fake-indexeddb final-handoff/staleness checks; independent code review; then actual cloud-browser selected-field preview/PNG download/cancel and original JSON comparison. Program tests do not count as real-device or OS-IME verification. All core/scene/media regression and type/build results plus browser evidence are recorded in FINAL-ACCEPTANCE after completion. Preserve v45's root redirect, responsive routes and all stage/media/data/privacy logic; rollback to v45 removes only the new card UI.
