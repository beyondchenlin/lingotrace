# LingoTrace · Total PRD v77

## Purpose
Let learners listen, type and review directly over the video through one quiet, transparent HUD while preserving native editing, verified learning records and the established visual anchors.

## Functions
- Borderless native typing with a neutral empty-word underline, optional letter/word guidance and lightweight check/next glyph.
- In-video listening/history controls with complete playback, repeat, help, storage, recovery and export access.
- Lightweight keyboard and settings glyphs; mobile or portrait keyboard hidden by default; a translucent landscape keyboard below the typing area.
- Native-size video, clamped to the viewport, with 0.5×, 1×, Fit and Fullscreen choices; independent follow-video/fixed-reference HUD sizing.
- Existing goal, flow, trend, title, camera, counter, scoring, records, permissions and media ownership remain intact.

## Acceptance
1. The four red-marked areas in the supplied 2026-10-11 screenshot no longer render as a top toolbar, instruction pill, placeholder/helper block or dark keyboard/select widgets.
2. Native selection, IME, paste, multiline editing and long-draft scrolling work; focus is visible and primary hit areas are at least 44 CSS px.
3. The empty underline is one constant neutral mark independent of the answer; hidden listening reveals no reference text, answer-target key or expected length. Assisted guidance still marks exposure truthfully.
4. Listening actions and record exports retain their real behavior; errors, missing observations, permissions and recording status remain visible when relevant.
5. The landscape keyboard sits below typing on a light transparent surface; mobile or portrait starts hidden and an observed software keyboard suppresses the page keyboard.
6. Video fits without cropping or accidental upscaling at 1×; Fit and actual Fullscreen are distinct; HUD mode and size keep drawing, native input, hit regions and recording aligned.
7. Focused tests, typecheck, aggregate tests/build and independent desktop/portrait browser checks identify exact passes and remaining limits before release.
