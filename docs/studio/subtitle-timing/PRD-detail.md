# LingoTrace 字幕边界校准详细增补（候选）

日期：2026-10-11。此文先于实现编写，作为上述总纲的细则；实际证据随后另记。

## 1. 范围及事实分层

在 public/subtitle-workbench 现有 C1 流程增加人工边界编辑。raw、source、run 及来源顺序不可变；candidate 保存当前派生状态，edits 追加所有文字／时间修改与撤销。本页并列转写／导入版本独立，新转写不覆盖人工稿。所有候选始终 needs-review，无正式训练引用或人工已核标签。

## 2. 时间编辑

选中段显示前／当前／后段文字和边界。数字框以秒为单位，支持至毫秒；滑块覆盖 0 到本次媒体时长。允许用户输入暂时无效值进行修正，两个端点在一次“保存边界”中原子验证。滑块每次 input 只改变暂存值，不逐像素写历史；保存产生一条 timing 修订。取消暂存恢复当前已保存 cue；选择其他 cue、并列初稿、重导入、重新推理、离开／关闭之前按现有未保存流程提示，不静默覆盖。

微调选择 1 / 10 / 100 ms，默认 10 ms。专用可聚焦操作区中 Left / Right 按所选步长移动所选起点或终点，Space 切换本次暂存段试听／暂停；不在 window、document、textarea、数字框或原生媒体上抢占快捷键。独立明确的按钮同样可操作。超过上下界时保留原值并给出说明，不静默夹取。鼠标滑块与数字框有完整 label；原生控件支持键盘，触控不宣称已验收。

保存要求当前播放器 readyState ≥ 1、有限正 duration、duration ≤ 60；使用与已识别原片及实际播放器一致的较保守时长。非法数值、空白、非有限、负数、end ≤ start、越界均拒绝；不以 0 替代未知。合法重叠只提示，不能阻止或自动改邻段。无改动不生成修订。异常原始 cue 可以人工修正当前范围，原始异常仍作为来源风险保留。

## 3. 试听与生命周期

“试听暂存段”按当前暂存起止；“试听开始附近／结束附近”给出边界前后各 0.5 秒、受媒体有效范围约束的上下文。界面说明它们是浏览器时间边界试听，并非样本／帧精确截音。未就绪、未知时长或无效暂存范围不可启动。时间输入、选择其他 cue／版本、撤销、保存、取消、导入或推理、隐藏页面、媒体出错都停止当前边界试听并撤销迟到播放权限；异步 play 成功后仍复核来源、任务及当前测量。此批不增加自动循环。

## 4. 对齐与版本协议

新时间修订前保留可读 subtitle-draft.v1；首次时间修订在新不可变对象中显式升级为 subtitle-draft.v2，保留原始 source/raw/run 和全部 v1 修订，在 v2 历史中加入完整起止与异常快照。升级不得改变源文本、模型原词或 v1 修订含义。v2 支持 text、timing、undo，重播历史校验当前候选全部可编辑字段，拒绝篡改、伪造有效对齐、未知字段、错误撤销或身份。旧 v1 读取器明确拒绝 v2。

时间编辑无论原词是否仍落在新边界内都保守标 stale，不均分、拉伸或平移原词时间；撤销精确恢复旧状态，只有恢复原有效映射时才恢复原有效资格。导入字幕无词级对齐也不伪造对齐。重新测量更短媒体时，历史保留，当前越界标风险，阻止该范围播放／VTT；JSON 仍可保留完整异常证据。撤销顺序与现有文字修订统一，撤销后新编辑产生新修订号，不能覆盖已存在版本。

## 5. 保存与出口

边界暂存和文字暂存分开保存；边界有独立取消按钮，文字沿用现有切换时放弃确认。任一未保存时不得把下载结果称作含该暂存改动。完整 JSON 保留原来源、原稿、当前候选及完整编辑链；VTT 只导出当前时间文字、保留合法重叠，仍待审核。v2 重开继续现有媒体 SHA-256＋大小身份检查与新测量复核。限额仍为 2,000 条编辑、8 MiB JSON 等 C1 原有预算；保存失败保留当前已保存与未保存输入。用户明确选择“放弃并继续”会先放弃暂存内容；随后导入失败时，已保存初稿仍保留，但不恢复已经明确放弃的暂存。这沿用 C1 的确认语义，取消确认则全部保留。

## 6. 必测矩阵与完成边界

- 数据：正常时间、0／媒体结尾、1 ms、空值、负数、倒置、NaN／Infinity、越界、合法重叠、异常来源修复；文字／时间交错、连续撤销、撤销后新分支、原始对象冻结与来源不变、v1 兼容、v2 导出重开、坏 JSON／伪造历史拒收、测量变化及预算。
- 组件行为：实际事件回调执行数字／鼠标／方向键／Space；文字输入 Space 与方向键不被劫持；保存、取消、下载拦截、换段／换版本确认、无改动、超界错误、播放结束边界、隐藏、迟到 play、媒体变化。
- 回归：既有字幕、媒体、训练／场景测试及类型检查／构建。若环境缺依赖、输入或浏览器验证，分别标未跑与失败，不能宣称全部通过。
- 独立审查后再申请浏览器实测与发布。无新权限／模型／LLM 或外发，不触碰 NPS 既有访问限制；本批完成不代表所有 C 条款完成。
