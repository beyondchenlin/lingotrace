# LingoTrace 字幕边界校准增补总纲（候选）

日期：2026-10-11。实施前合同，尚未宣称验收或发布。

基线：已核验的 v76 发布源码 98faf71bd72b09d346e0b89b72fa6a99fc363edc。补充 v1.4.14 的 C09–C11、C14；此前总纲、详细 PRD、C1、连续听与紧凑输入合同全部保留。

## 本批目标

在现有本机字幕准备页，导入字幕或生成模型初稿后，可人工修改选中候选段的开始与结束时间，试听边界、撤销并下载带完整来源及修订链的初稿。文字、时间、对齐资格分别表达，不把人工时间调整冒充重新词级对齐。

## 本批功能

- 显示当前段、前后段、实测原片时长与原始时间；允许合法重叠，不自动裁剪邻段或重排来源顺序。
- 通过秒数输入、鼠标拖动有界时间滑块及明确焦点内的方向键微调，默认 10 ms，可选择 1 / 10 / 100 ms。无实际帧时间戳，不称逐帧或帧精确。
- 边界编辑为未提交暂存；用户明确保存才追加修订。可试听暂存范围或起止附近原声，Space 只在专用时间控制区焦点内控制播放；文字与数字输入仍保留系统编辑行为。
- 保存校验 0 ≤ start < end ≤ 当前已知且可用媒体时长。错误不夹取、不清空、不中断原始来源保留；媒体未就绪不能保存边界或试听。
- 时间变化使该段派生词对齐失效，原词时间、原字幕和模型记录不改。撤销追加可追溯记录，并恢复对应旧时间、文字与对齐状态。
- JSON 支持原 v1 输入；含新时间修订的初稿使用明确新协议，旧版读取器拒绝，不把新意义塞进旧格式。重新导入核验相同媒体字节与本次时长。

## 未交付边界

本批不新增模型、云端服务、LLM、网络权限或付费；不自动采用为训练参考，不改旧答案／成绩。音频波形、合并拆句、正式参考确认、词级重对齐及全 C 验收仍为后续范围。仍使用 C1 的 32 MiB / 60 秒限额与本页内存、显式下载保存规则。

## 完成门槛

程序测试覆盖来源不变、有效／异常时间、合法重叠、撤销／版本分支、旧格式重开、焦点键盘行为、取消与播放器迟到回调。独立代码审查与构建通过后，另由主任务进行真实浏览器验证；通过前不部署。测试替身不算浏览器或实体设备验收。
