## 审查发现及复验

### R1：导出与编辑使用不一致时长（已修复）

初版 `main.js` 的 `download()` 只使用播放器当前时长，而编辑和暂存试听使用首次识别与播放器时长的较小值。独立探针构造已识别 5 秒、播放器 8 秒、原字幕结束 7 秒的 v2 初稿：保存/试听拒绝该范围，但 VTT 曾成功导出。

现在 `download()` 复用 `timingDuration()`，包含保守时长、就绪、错误及源 URL 检查。相同探针不再导出越界 VTT；新增真实回调测试也验证 JSON 保留 5 秒测量。历史及原始异常仍可通过 JSON 保存。

### R2：修复越界字幕后遗失来源风险提示（已修复）

初版把原字幕 end=7 秒修为有效范围后，当前候选的 `out-of-bounds` 消失，但没有独立的原始越界风险。源码和原始数字没有丢失；问题在于风险显示不再履行合同。

现在 v2 区分当前原始数据相对本次测量的 `raw-out-of-bounds` 与相对首次识别的 `raw-original-out-of-bounds`。独立复验中，合法修复仍可试听/导出，两个来源风险均保留；合法重叠不被阻止。重新测量预算也为 v2 字幕/原生轨保留对应诊断空间，避免近预算文件重新打开时因新增提示失败。UI 对非 ASR 来源明确称“原始字幕”。

### 合同澄清

已检查 §5 明确区分保存失败与用户明确选择“放弃并继续”：保存失败保留暂存；显式放弃先执行，后续替换失败不会恢复已放弃的暂存。取消确认保留输入和原版本。

低优先级文案核对也已修正：§5 现在准确说明独立保存文字/边界、仅边界提供独立取消按钮，文字沿用现有保存/切换时确认放弃流程。没有未关闭的审查发现。

## 重点检查结果

- **原始证据**：时间编辑新建并深度冻结对象；`source` 原始身份、原字幕、`raw`、模型 `run`、词时间与源序不被移动或覆盖。实测信息与首次信息分别保留。
- **v1/v2 协议**：文本-only 仍为 v1；首次实际时间改动明确升级 v2；保留准确 v1 历史，并验证展开前缀。用基线提交的真实旧读取器独立验证 v2 被拒绝，用新读取器验证旧 v1 内容不变。
- **历史与撤销**：重播校验 start/end/anomalies/text/alignment/revision；时间修改不能夹带文字或伪造有效对齐。混合文本/时间修订按统一栈撤销，撤销后新分支修订号递增，原历史保留。
- **对齐诚实性**：即使新边界仍包含全部原词，编辑也标 stale；手工输入旧时间不会自动恢复 valid。仅精确撤销到合法原映射时恢复其原资格；所有候选保持 needs-review。
- **时间安全**：空白、非有限、负值、零/倒置及越界拒绝；两端一次提交；不静默夹取。更短测量不抹去历史，但阻止越界当前范围试听/VTT；JSON 可保留异常。
- **合法重叠**：可保留并提示，不剪裁邻段或重排内部来源；仅 VTT 按开始时间和源序排序。
- **焦点与暂存**：快捷键绑定专用 pad 且检查精确事件目标、组合键、输入法及 Space 重复；不绑定全局键盘，不截获文字/数字框。文本/边界分别保存时保留另一侧暂存；下载拦截未保存改动；换段/版本确认及取消有实际回调测试。
- **播放生命周期**：输入变更、保存、取消、切换、隐藏和媒体错误会撤销播放权限；异步 play 后复核所有权、源、时长、就绪/错误与播放位置。边界仅作为浏览器级监听/停止，不宣称采样或帧精度。
- **安全边界**：无新增上传、网络地址、模型/权限、训练采用或成绩写入入口。输入渲染仍使用纯文本；闭合 schema、重复 JSON 键拒绝、不可执行原始内容及预算限制维持。既有固定资源按需下载不属于本次新增能力。
