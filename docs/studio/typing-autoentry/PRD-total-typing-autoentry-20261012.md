# LingoTrace 打字驱动视频自动播放总纲增补

版本：2026-10-12 候选审阅版第 1 版。配套《LingoTrace 打字驱动视频自动播放详细 PRD 增补》。本增补另存，保留 v1.4.8 原件、执行校准版和全部历史 Follow 文档；不以更高版本号推定未经确认的条款获批。

状态：本版补回执行校准版遗漏的 Follow 要求，并记录本次可信输入自动进入的目标。本次交付范围确定为合格 NPS 普通跟打自动进入；咖啡馆校正版支持未实现，相关探索不进入生产交付。实际实现验收和独立审查尚无完成结论。没有新版本发布或真人手机验收结论。现有源码中已经存在的 Start Follow 与新自动进入能力分别报告。

## 目的

本次让用户在符合资格的 NPS 普通跟打练习中，真实开始打字即可带动当前句原视频和原声，并根据真实输入节奏平滑调速。用户“打字驱动原视频和原声”的整体目标继续保留；其他素材路径尚未完成，不能以本批 NPS 范围缩减整体目标或宣称全产品闭环。用户在 2026-10-12 明确指出：“我记得要实现打字的时候根据打字速度自动播放视频的 还没有实现 还是忘记了”。本次将这项实际使用目标置于优先级首位。

原 v1.4.8 只含真实输入口径、HUD 输入能量及媒体事件等基础合同，尚未包含后来才形成的 Follow 具体条款。2026-10-12 执行校准版虽保留连续听和媒体驱动的估算节奏，却漏收了后续打字驱动媒体合同。本增补修正这项文档遗漏，不改写原件或历史交付事实。

## 本次新增和既有能力

1. **可信输入自动进入**：在已核验无旧练习可恢复的新鲜页面（默认 NPS）、用户明确成功新开练习，或在未恢复的新鲜练习中用户明确导航到另一句之后，为当前引擎／会话／句准备一次自动进入机会；同一新练习中已经获得过机会的句子，离开后返回也不重新准备。准备和导航本身无声；下一次可证实的真实末尾追加输入才触发 Follow，不要求先找到 Start Follow。候选应显示待输入状态，并允许打字前停止。不能以聚焦、键盘展示、待机动画、粘贴、恢复旧稿或模拟事件触发。第一次编辑若不合格或当前资格受阻，便撤销机会；初次 IME 空提交或取消也不保留自动重试。
2. **保留显式控制**：既有 Start Follow 入口与明确状态、实际倍速及停止控制保留。v85 的默认关闭、显式选择后才播放是历史入口合同；本次只更新入口政策，保留载入不发声和显式重启。手动暂停或停止耗尽本句自动机会，后续打字不得悄悄推翻；同句须显式 Start，用户明确进入本练习中尚未获得机会的另一句，才可获得该新句机会。
3. **按真实节奏调速**：沿用句级估算，起步 0.8×，在 0.5–1.5× 内平滑变化，每秒最多变化 0.25 倍速单位。真实错字也可作为临时输入节奏，正确性不是速度条件。临时估算不能冒充 CPM、WPM、掌握度或奖励。
4. **同源声画**：原声和原视频始终使用同一个已验证原生媒体元素及时间轴。进入时最多进行既有的一次当前句首定位，不逐字／逐词跳播，不替换配音、重编码或添加第二条声音。
5. **保留停打缓降**：超过 1.5 秒没有符合条件的提交输入，沿用 v85 idle-coasting，逐步降至 0.5×并继续到当前已登记字幕句尾。新的合格输入只重新估速，不增加 play 或 seek。句尾停止并解除控制，后续打字不自行重播或切下一句。
6. **保护手动和安全状态**：手动暂停、普通播放／重播／定位／倍速、检查、换句或换源、Hidden、失焦、后台、录制、模态操作及不安全原生事件优先。IME 预编辑暂停，最终可信提交只在仍有效的同一等待范围内恢复。刷新、被动恢复、回前台或显示参考本身均不自动发声。
7. **保护学习事实**：自动进入和调速不制造输入、attempt、提交、完成、奖励、学习时间或听力观察；不改 CPM、旧记录、保存模式、导出、媒体来源和录制合同。真实编辑和显式检查仍走原路径。

## 适用范围与明确限制

本批仅支持已验证、注册且与当前练习绑定的 NPS 课程，要求参考真实显示、可编辑练习、前台及无其他媒体 owner、录制或阻挡状态。无历史新页使用既有 NPS 默认课程；恢复到咖啡馆的旧练习不被擅自切换。

咖啡馆校正版仍未实现 Follow。保存版本、实际 SHA／lease／时长／范围有效，只证明内容身份和合法区间；目前没有不可伪造的本页完成预听证据和明确采用链，预览终点也可能由 seek 到达，不能视为已经听校。本轮撤回校正版生产候选，不计其探索代码或测试为交付成果。未来仍须为相关校正／结构输出句建立真实预听完成、显式采用和精确版本／媒体资格，之后再接入。

咖啡馆原版固定六秒槽不等于已验证完整时轴；原版无核验直链回退、本机自由视频、其他未经资格验证的素材仍禁用。普通 ListeningPlayer 的听或打模式、隐藏听写和被动恢复的整个练习也不在自动进入范围；恢复后真实编辑或显式选另一句均不静默重新准备，需要合格后显式 Start 或成功新开练习。未来校正版支持须另有精确实现、独审和实际验收证据，本批不能称全部课程已支持。

句级字幕范围只支持估算速度，不提供经声学校准的逐词时间。原始短句可能在估算充分前结束，慢于 0.5× 的用户仍可能打不完。精确逐词同步、自动选择或播放下一句、全课程适配以及新的 AI／字幕生成能力不在本次交付范围。用户主动选择另一句只准备下一次输入启动机会，不形成跨句自动播放。

浏览器可能拒绝实际音频播放。失败必须显示真实状态和显式恢复入口，不循环自动重试，不以静音或其他音源伪装成功。原生手势链和真实声音输出必须分别验收。

## 验收标准

1. 有效真实输入可以在配套详细稿第 5 节进入规则及已核验素材矩阵内自动启动当前句；不要求先手动点击 Follow。来源不明、合成、粘贴、删除、替换、中间编辑、未提交 IME、取消组合、恢复和待机都不能自动启动或制造速度。
2. UI 中显式开始、停止、真实状态和原生实际倍速保持可发现；英中含义一致，句级估算限制清楚，不抢输入焦点或改变 HUD 已认可几何。
3. 调速范围、观察窗、资格、防抖和停打缓降与详细稿一致；无逐字 seek、无自动检查、完成或下一句。句尾和异常停止独立于用户是否打对。
4. 手动停止后继续打字不重启。隐藏参考、后台、失焦、源／句变化、录制和模态状态中不自动启动；迟到 promise、native event 或定时器不能复活已取消或较新的播放 owner。
5. 自动进入无额外成绩或历史副作用；真实编辑只执行一次。IME 尾随事件不重复计数，隐私差分测试通过，待机与媒体驱动节奏均不充当真实输入。
6. 保留 Start Follow 原手势同步发起原生 play 和既有音频路由恢复的合同；新的输入手势路径不能假定平台必然接受。拒绝和失效结果如实可恢复。
7. 行为红／绿测试、类型检查和独审对应精确源码；构建、发布身份、浏览器视频运动／倍速变化／原声、手机键盘与听觉体验分别列明。任一程序测试通过不替代实际设备验收。
