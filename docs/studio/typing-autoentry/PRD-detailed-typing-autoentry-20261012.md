## 1 用户目标与本次变更

2026-10-12 用户原话：“我记得要实现打字的时候根据打字速度自动播放视频的 还没有实现 还是忘记了”。本次目标是在已有授权的普通工程范围内补足可信实际打字自动进入 Follow，并补回成对 PRD 遗漏。

已有实现要求用户先点击 Start Follow，随后按真实输入估算倍速。本次新增目标是符合条件的第一次真实 committed append 可以成为自动进入动作，同时保留显式 Start Follow。变化仅限入口和必要的暂态再进入规则；调速、句尾、输入真实性、隐私、媒体所有权及录制隔离继续遵守本稿保留条款。本批只交付合格 NPS 普通跟打的自动入口。咖啡馆校正版缺少真实完成预听及明确采用链，本轮不接入；原版六秒槽、无核验回退或自由视频继续禁用。用户希望真实打字驱动原媒体的整体目标保持，其他素材路径明确列为未完成，不能因本批范围有限而降低整体目标。

## 3 保留的 v85 Follow 功能合同

### 3.1 显式入口与资格

FOL 01：保留显式 Start Follow 的开始／停止入口、当前状态和实际原生倍速，英中含义一致；放在既有输入辅助区，不挪已认可 HUD 锚点，不覆盖原生编辑行或关键检查入口。焦点、IME、Enter、Space、方向键和原生选区仍由编辑器规则优先。

FOL 02：v85 保留范围要求注册且验证过的 NPS 源、固定会话和当前句身份、有限媒体时长和有效可播放范围、实际显示并记录相应辅助暴露的参考、前台可编辑练习、可证明真实输入来源。ListeningPlayer、参考预听、历史／复盘、模态、来源加载／恢复失败、渲染失效和录制准备／运行／收尾均阻挡。校正版的未完成资格缺口见第 5.2 节；本批不接入，不能单删 NPS 判定而开放所有素材。

FOL 03：显式 Start 在同一次有效用户手势中撤销旧普通播放／重复 owner、记录原手动速率、进行至多一次句首定位，并发起原生 play 与已存在音频路由的 resume。二者分别观察；均完成且范围仍有效才报告启动成功。拒绝后暂停并提供显式重试，不自动循环，不切替代 URL 或声音。

### 3.2 同源同钟与控制所有权

FOL 04：同一个已验证原生课程媒体元素承载画面、原声、位置和 playbackRate；保持既有音频路由、监听静音、音量及画面比例。平台可用时保持原生音调保护。不得增加第二个音频源、合成配音、时伸库、服务器处理、重编码、音轨复制或媒体内容变化。

FOL 05：仅进入动作的一次句首定位，以及后续用户显式重播／定位，能够改变位置。调速器不能按字符、正确前缀、匹配词数、播放百分比或定时 tick 写 currentTime。普通 Play、Replay、seek、手动倍速均先退出 Follow，再执行用户动作。

FOL 06：每次原生事件、速率写入、边界回调和异步结果携带 source／cue／owner／epoch／command 身份。失效或不明归属即退出。只在仍拥有先前速率令牌及预期原生值时恢复旧手动速率；不能覆盖新手动速率。旧源清理不能暂停或调速较新的媒体 owner。

### 3.3 临时输入估算

FOL 07：只使用可证实的真实末尾追加，包括最终 IME 提交恰好一次。前后原生文本、选择范围、inputType、提交数据和可信来源应相互一致。中间输入、选区替换、自动更正／填充、粘贴／拖放、删除／剪切、撤销／重做、历史恢复、程序编辑、IME 预编辑或来源不明不制造正速度；它们仍保留原生编辑能力及原学习语义。

FOL 08：输入正确性不参与估速，真实错字与对字同样计临时活动，但只由现有显式 Check 产生判断。非追加编辑使活动 Follow 暂停退出，不能跟随粘贴文字、倒播或自动完成。控制器只短期保留有界计数和时间，不另存键盘／文字流水。

| 参数 | 保留值与解释 |
|---|---|
| 起步与未充分估算 | 0.80× |
| 自适应范围 | 0.50–1.50× |
| 更新频率 | 不快于每 200ms 一次 |
| 最近输入窗 | 最多 3000ms；限同源同句同 owner 段 |
| 估算充分性 | 至少 1000ms 覆盖、两次有效提交相隔至少 250ms |
| 停打阈值 | 距最后有效输入或开始达到 1500ms |
| 最大变化率 | 每墙钟秒 0.25 倍速单位 |
| 死区 | 小于 0.02 的变化不写入；无另行批准的独立迟滞状态 |
| 观察间隙保护 | 不可观察、时钟回退或超过现有 1000ms 观察间隙使范围失效 |
| 平滑积分 | 使用真实单调时间，每次最多积分 200ms，不补算挂起时长 |

对实际显示且有效的当前句，名义速度为句中文字素数除以已验证句时长；临时输入速度为本窗有效追加字素数除以观察时长；两者相除后夹到允许范围，再按斜率和死区渐变。Unicode 字素分段保持与产品一致，不能把 IME 选字伪造成逐键事件。读取实际生效的原生倍速用于显示，不把未生效目标当当前值。这些是已有候选调参值，不是经过真人验证的最佳值。

### 3.4 停打和终止

FOL 09：1500ms 停打进入 idle-coasting，仍保持 following。清除过期估算，逐渐降至 0.5×，原声和视频继续到已登记当前句尾；输入恢复仅重新估速，不增加播放或 seek。不得使用旧稿“停打即静音暂停”规则。

FOL 10：到当前句尾暂停并解除范围，即使用户还在打字也不自动下一句，后续打字不能重启本句。提前打完不跳至结尾、不判断完成；保留原生边界检查及时间事件双层保护，测量实际超出边界量，不宣称采样级或逐词精度。

FOL 11：IME 组合开始保守暂停，不读取预编辑制造速度。最终可信提交只在仍合格的同一组合等待 epoch 内恢复；取消组合不自行恢复。再次估算前沿用起步速率。手动暂停、Blur／后台、Hidden、换源／句、检查、复盘、录制或失效不是 idle，不得套用输入自动恢复。

## 4 事实 隐私与兼容性

控制器没有评分、attempt、完成、奖励、历史、导出或仓库写入能力。真实输入仍由同一原生路径提交一次；自动进入不得重复输入事实。CPM 继续原 5 秒观察合同，不能改用本临时 3 秒速率。媒体进度不能生成输入成果、练习时间或听力观察。

原本普通播放具有 listening 冻结时，开始 Follow 沿用既有显式 Pause 的一次冻结／idle 交接；不能把这一已有交接称为全快照零变化。原本已暂停练习的纯控制流程应保持完整学习快照和固定时点导出不变；其后变化只来自真实输入及已有显式动作。

Hidden 应在渲染前同步撤销 Follow，并清除参考推导的长度、速率、标签与几何；从隐藏页不能为本功能读取隐藏目标长度。相同外部动作、不同隐藏答案的 UI 和自动控制应一致。不能为了启动 Follow 自动显示答案或修改辅助条件。

刷新、bfcache、历史恢复或回前台不恢复 active Follow／运行估算／待执行 play。记录关闭不被本功能绕过；无额外保存字段或迁移。录制准备、运行、收尾阻挡 Follow；启动录制先完成原 Follow 退出和暂停交接，不改变 F03 音轨、权限和收尾合同。

## 5 可信输入自动进入候选合同

AUTO 01：为当前引擎、会话和句建立一次性的内存自动进入机会，仅有三种来源：初始化已完成且明确查无可恢复记录；用户明确成功新开练习；未恢复的新鲜练习中用户明确导航到另一句。准备和导航本身不播放、不显示启动成功。同一新练习内记录已经准备过机会的句；离开后再返回已准备过的句不重新准备，不能借导航绕过手动停止。机会、已准备句集合和 active Follow 均不持久化。页面应显示待输入状态及可在打字前操作的停止入口。

AUTO 02：下一次用户在当前原生练习框实际完成的可信 committed tail append 才能消费机会并进入。单独 keydown、beforeinput 意图、焦点、光标、未改变文本、程序 input 或重放不足以启动。最终可信 IME 提交允许恰好一次，预编辑及取消组合不启动。真实文本立即按原规则编辑，不等待视频、动画或数据库操作。自动入口不重新聚焦、不移动光标／选区；显式 Start 原有的一次主动聚焦另行保留。

AUTO 03：复用原 Follow 的身份、播放范围、原声、速率、状态、原生手势链和拒绝处理能力；不得新建并行控制器，不得使用 Listening 视觉节奏、待机动画、匹配前缀或已存草稿当自动输入。机会消费必须在异步 play 结果前完成，拒绝后不能每打一个字符循环重试。实际原生播放受平台限制时提供显式 Start 恢复入口。

AUTO 04：手动 Stop／Pause／Play／Replay／seek／倍速、检查、Hidden、失焦、后台、pagehide、录制、模态／复盘等中断应撤销机会，即使 Follow 尚未启动。回前台、focus、显示参考、关闭模态或恢复旧稿不能重新准备。用户在同一句继续输入不能复活，须显式 Start；明确导航到另一句才可为新句准备机会。

AUTO 05：被动恢复的整个练习不允许静默重新准备，即使经真实编辑激活练习，或用户显式进入不同句也不自动准备。符合其余资格后用户可显式 Start；成功新开练习才可建立新练习的自动机会。程序导航、后台导航、恢复选句、相同句重复选择均不能伪装用户明确进入另一句。显式检查不会自动下一句；用户明确执行 Next 导航至另一句后才允许该新句机会。

AUTO 06：已准备机会后，第一次观察到的编辑即进行一次资格决策；任何前置资格受阻都耗尽机会，不等待后续字符重试。粘贴、删除、中间编辑、替换、未知来源、程序编辑等不合格操作撤销机会，初次 IME 的空提交或取消也撤销。以后移除阻挡、恢复正常输入或定时器 tick 均不重启。已活动 Follow 的原有组合等待／取消规则仍由其控制器处理，不把新的首次入口取消规则混入活动控制器。

### 5.1 进入与再进入矩阵

| 状态或动作 | 自动机会和播放行为 | 核验重点 |
|---|---|---|
| 初始化完成，明确没有可恢复记录 | 可准备一次；载入不播，下一真实末尾追加才消费 | `saved === null` 的实际成功分支，不把未知或失败当空 |
| 用户明确成功新开练习 | 当前新会话／句可准备一次；动作本身无声 | 成功完成后绑定新引擎／会话／句 |
| 用户明确导航到另一句 | 只为本练习尚未准备过机会的新句准备一次；导航本身不播 | 区分显式新句与程序／恢复／后台导航、同句重选及离开后返回已准备句 |
| 合格真实末尾追加 | 消费当前机会，经完整资格检查启动 | 文本和原学习事件只提交一次，native play 同步链 |
| 最终可信 IME 提交 | 可消费一次；尾随 input 不重复 | 组合证据和原生最终值一致；不把 preedit 当提交 |
| 粘贴、删除、替换、中间编辑、撤销、未知／程序输入 | 撤销机会，不自动入、不制造速度 | 后续正常字符不能重试 |
| 第一次编辑时任一资格受阻 | 耗尽机会，不播放；需显式恢复 | 媒体稍后就绪或阻挡移除不复活 |
| 初次 IME 空提交／取消 | 撤销机会，不启动 | 与活动 Follow 的组合等待／取消区分 |
| 被动恢复的整个练习，包括真实激活编辑和显式选择不同句 | 不准备、不自动入；合格后显式 Start 或成功新练习恢复 | 恢复值和之前许可不变成新机会 |
| 手动停止／暂停后同句继续输入 | 不重启；显式 Start 可重新控制 | 停止键在待输入和活动态都有效 |
| 句尾结束后同句继续输入 | 不重播、不下一句 | 保持 ended；明确进入未准备过机会的新句才产生机会 |
| Hidden／show、失焦／focus、后台／前台、pagehide | 中断撤销；返回不重备、不复活 | 未启动待输入态也撤销 |
| 检查、复盘、模态、录制准备／运行／收尾 | 中断撤销；结束阻挡不重备 | 明确 Next 至另一句属于独立新句导航 |
| 原生 play 或音频 route 拒绝 | 机会已消费，暂停，需显式 Start | 后续字符无重试循环 |
| 新源／新 owner 与旧异步结果交错 | 原范围失效，无权操作新 owner | 旧请求、速率令牌、迟到事件均隔离 |

### 5.2 素材和模式资格矩阵

| 素材或模式 | 候选资格 | 需要的证明 |

## 6 验收用例

### 6.1 自动入口与实际输入

AE 01：先证明有效新鲜状态中仅打字不启动的原缺口；最终方案下同一真实追加可启动，输入文本及学习事件只变化一次。测试应覆盖真实处理函数，不以纯策略夹具代替完整接线。

AE 02：对每个排除来源单独验证没有新 play、seek 或速率写入；包括伪造可信标志不能穿过真实事件边界、粘贴、多字输入来源不明、删除、中间插入、选区替换、撤销、预编辑、取消组合、恢复和重放。

AE 03：最终 IME 的 compositionend 与尾随 input 组合只计一次，文本先正确上屏；空提交和最终数据无法确认均不制造入口。适用平台的真实 IME 验收另列。

AE 04：逐格验证第 5.1 节进入矩阵，并在用例名中标明状态及是否允许重新自动进入；覆盖无记录初始化、显式新练习、显式新句、同句重选、离开后返回已准备句、程序／后台／恢复导航和打字前 Stop；第一编辑不合格或受阻及初次 IME 取消都耗尽机会。第 5.2 节每类素材和模式须有资格通过／拒绝证据，尤其不得把原版六秒槽或无验回退当校正版，本轮所有校正版均不得触发 Follow，不能把其旧版本、schema 或 lineage 升为资格。后续预听／采用流程不在本轮测试完成数中。

### 6.2 调速与媒体

AE 05：原声和画面保持一个元素；进入最多一次句首定位。足够覆盖前为0.8×；不同快慢输入得到合法速率，200ms／0.25/s／0.02 及0.5–1.5×边界成立，无逐字 seek。

AE 06：1500ms停打后缓降、继续至句尾；新输入只重估速度，句尾停止后不能打字复活。短句、长句、慢输入、错误输入及原生速率拒绝或钳制分别覆盖。

AE 07：显式 Start 保留同步原生 play 和既有路由 resume；新输入自动入口的同步和结果次序按定案设计验证。play／route 任一失败时，不报成功、不无界重试、不清稿；迟到失败不能暂停较新 owner。

### 6.3 手动 所有权和隐私

AE 08：手动暂停、普通 Play、Replay、seek、任意手动倍速均取得控制；原手动速率只在令牌仍属于 Follow 时恢复，后续输入不能撤销手动决定。

AE 09：后台、Blur、Hidden、切源／句、pagehide、卸载、录制、检查／复盘和模态在启动中、播放中、缓冲中、组合等待中均应正确退出。失效定时器、native event 和 promise 不能自动复活或伤害新 owner。

AE 10：不同隐藏目标在相同行为下不产生不同 Follow UI、数字、几何或自动控制；绝不为 Follow 自动显示参考。真输入、CPM、历史、记录 OFF、导出和奖励回归保持，允许的单次普通播放交接明确核对。

### 6.4 证据和交付

AE 11：有效行为红／绿、聚焦回归、受影响完整回归、类型检查及独审均绑定精确源码；夹具装载错误不冒称产品红证据。依赖、锁文件、原资产、媒体来源与旧 PRD 是否变化分别列明。
