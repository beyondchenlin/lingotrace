## Architecture

Next.js16.4.0, React19.3.0, TypeScript7.0.2, Motion14.0.0, locked npm dependencies. Static export supplies/studio without a server, account or cloud backend. React handles semantic controls and actual DOM input; a persistent Canvas2D scene composites learning media,camera,HUD,subtitle,feedback and lightweight vector rewards. Canvas reads an external engine/ref; a draw frame does not dispatch a learning event or rerender the React tree. Motion is restricted to product panels/transitions. Rive is an asset interface only until an actual licensed animation is integrated.

The typed deterministic reducer owns attempts,first/retry conditions,hints,exposure,paste and earned target positions. A separate monotonic clock produces replayable effective-time events. Renderer,review,JSON/CSV and IndexedDB snapshots read the same facts. Initial live values are zero. A conspicuously labeled reference fixture may supply68/24/4 only for visual comparison, cannot submit,record real accomplishments or persist scores.

## Scene and capture

Default view matches06: full learning scene,light top progress,camera inset at upper-right,subtitle and actual input,large bottom HUD and playback row. Camera opens only on explicit user click; it has independent stop/device state. Scene layout supports learning-primary,camera-primary,split and PiP using the same layers. Local selected files remain device-local and have no automatic transcript/grading.

Explicit scene recording uses Canvas.captureStream so the rendered video,camera,HUD,subtitle and current draft are truly captured together. No OS screen capture is started. Audio defaults off; lesson audio and microphone require explicit selection. Record chunks are persisted locally and unpinned recordings expire after7days when the app next executes cleanup. Downloads and browser retention are separate. No guarantee of background cleanup,permanent browser storage or independently playable interrupted chunks. No AI speech scoring,remote inference or external upload.

Pointer drag, proportional resize, four-corner docking, per-item/reset-all and keyboard equivalents share constrained logical geometry. A full-stage background must be reduced before it has room to move. HUD controls do not cover the fixed input/player zones; media remains behind the HUD. Review now derives actual pace points by replaying the original reducer.
