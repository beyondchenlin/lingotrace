# LingoTrace · Total PRD v78

## Purpose
Keep learning readable over changing video brightness, with polished lightweight settings and a larger native typing surface that offers a complete optional reference.

## Functions
- Smooth, continuously linear per-HUD-region video-brightness adaptation of dark translucent backings, entirely local with an honest unreadable-source fallback.
- One coherent secondary settings-panel design with readable fields, clear grouping, keyboard focus and touch-sized controls.
- Larger borderless native typing with the complete current cue shown in pale text by default; actual typed glyphs replace the corresponding reference positions, and Hide reference enables dictation.
- Compatible Training/listening history views keep valid record types separate while preserving genuine unreadable-record warnings and stored data.
- Native editing, assisted-exposure truth, strict hidden-mode privacy, mobile keyboard defaults, video/HUD sizing and shared recording presentation remain intact.

## Acceptance
1. Dark, intermediate and bright frames produce corresponding continuous linear backing opacity, smoothly over time rather than threshold switching; inaccessible frames use a conservative readable fallback.
2. Goal, title, flow, trend, typing, keyboard and transport stay legible without changing their established anchors; no frames leave the browser or enter storage.
3. Settings fit desktop and portrait viewports, retain all actions, and support visible focus, 44 CSS-pixel targets, Escape and outside dismissal.
4. The whole current reference is available in the larger scrollable editor without entering the textarea value or real input/score records; only actual edits become input.
5. Reference exposure is truthfully assisted on a later real attempt and its pending identity survives same-session refresh while history is enabled. Hiding it removes reference text, target keys, expected-length masks and reference-derived accessibility text; hiding does not erase exposure already seen.
6. Selection, IME, paste, multiline text, scrolling, check/next and recording text alignment remain native and consistent. Mobile/portrait passive-keyboard defaults remain hidden.
7. Exact-source tests, independent review and cloud-browser bright/dark/typing/hidden/portrait checks pass before publication; physical-device limits remain explicit.
8. A valid listening record must not be classified as corrupt Training history or block ordinary recovery; malformed or unknown records remain preserved, visible errors.
